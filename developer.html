Behind the projects

Meet the developer

Bringing classroom experience and software development together.

ICT teacher · Software developer

Ngonidzaishe Handoni

nhandoni@gmail.com

I am an ICT teacher and software developer with an interest in building tools that make everyday work more manageable. Working in education has given me a practical understanding of how people use technology, especially when time and resources are limited.

I have taught ICT since 2018 and started developing web applications in 2017. My approach is straightforward: understand the problem, build something useful, test it with real users and improve it over time.

Through NHA EduTech, I share selected projects and the lessons I have learned from designing and developing them.

Background

My journey

2017

Getting started with web development

I began building web applications using PHP and MySQL, learning how to connect interfaces to databases and create tools that work beyond a static webpage.

2018–present

Teaching ICT

Since 2018, I have worked as an ICT teacher. Teaching has strengthened my focus on clarity, accessibility and technology that solves practical problems for its users.

2025

Expanding my development toolkit

I began using Python, Flask and React in my development work, broadening the kinds of web applications and interfaces I could build.

Today

Building and learning

I continue developing practical applications, combining experience from education with an interest in reliable, maintainable software.

How I work

What guides my development

Start with the user

Understand the process and the people involved before choosing features.

Keep it practical

Prioritise clear workflows and straightforward interfaces over unnecessary complexity.

Improve through use

Test carefully, listen to feedback and make changes that genuinely help.

Technologies I have worked with: PHP, MySQL, Python, Flask, React, HTML, CSS and SQL.
